🔵 Google – ett klick, alla appar

Ej kopplad

Logga in med ditt Google-konto så får AI:n och dina botar tillgång till Gmail, Kalender, Drive, Sheets, Docs, Tasks och Kontakter. Inga API-nycklar behövs.

Första gången: aktivera Google-inloggning (engångsinställning, ~5 min)

Google kräver att appen registreras en gång. Därefter loggar alla in med ett klick.

  1. Gå till console.cloud.google.com → APIs & Services → Credentials och skapa ett projekt (t.ex. Agent Flow).
  2. OAuth consent screen → External → fyll i namn + din e-post → lägg till dig själv som Test user.
  3. Enable APIs: Gmail API, Google Calendar API, Google Drive API, Google Sheets API, Google Docs API, Tasks API, People API.
  4. Create Credentials → OAuth client ID → Web application. Lägg till denna Authorized redirect URI:
    …
  5. Klistra in Client ID och Client Secret här nedan (eller sätt GOOGLE_CLIENT_ID / GOOGLE_CLIENT_SECRET som miljövariabler).

Så här kopplar du en gratis Supabase-databas (engångsinställning, ~5 min)
  1. Skapa ett konto på supabase.com och ett nytt projekt (gratisnivån räcker – inga betalkort behövs).
  2. Öppna SQL Editor → klistra in SQL:en nedan → Run.
  3. Gå till Settings → API och kopiera Project URL samt service_role-nyckeln (den hemliga – aldrig i webbläsaren).
  4. I Render → din tjänst → Environment: lägg in variablerna nedan och spara (tjänsten startar om automatiskt).
  5. Ladda om den här sidan – panelen ska visa Allt klart. Klicka sedan på Logga in med Google.
