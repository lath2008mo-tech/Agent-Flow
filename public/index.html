🛒 Shopify

Ej ansluten

Skapa en Custom App i Shopify-admin och klistra in Admin API-token här.

Så här gör du (tar 2 minuter)
  1. Gå till Butiksdin admin → Appar → Utveckla appar (eller admin.shopify.com/store/DIN-BUTIK/apps/development).
  2. Klicka Skapa en app → ge den namnet t.ex. Agent Flow.
  3. Gå till Configuration → Admin API integration → Configure.
  4. Välj behörigheter (scopes): read_products, write_products, read_orders, write_orders, read_customers, read_inventory, write_inventory, read_price_rules, write_price_rules, read_content.
  5. Spara och klicka Install app.
  6. Kopiera Admin API access token (börjar med shpat_) och klistra in nedan.
